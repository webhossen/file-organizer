# File Organizer 1.0.0

Initial public release of **File Organizer**, a safe, fast CLI that sorts files
into subfolders by extension or category.

## Highlights

- **Two sorting modes:** `--by extension` (default) and `--by category`.
- **Safe by default:** never overwrites; collisions become `name_1.ext`.
- **Dry-run preview:** `--dry-run` prints the plan without touching the disk.
- **Recursive mode:** `--recursive` collects files from nested folders.
- **Ignore globs:** repeatable `--ignore` patterns.
- **Hidden-file control:** `--skip-hidden` leaves dotfiles and dot-directories alone.
- **Pure standard library:** no runtime dependencies.
- **Cross-platform:** Windows, macOS, and Linux.
- **Tested:** 22 pytest tests and CI on Python 3.10–3.14.
- **Standalone build:** PyInstaller recipe and Windows executable.

## Installation

```console
git clone https://github.com/webhossen/file-organizer.git
cd file-organizer
pipx install .
```

Or with pip:

```console
python -m pip install .
```

## Quick start

```console
file-organizer ~/Downloads
file-organizer ~/Downloads --by category --dry-run
file-organizer . --recursive --ignore "*.tmp"
```
