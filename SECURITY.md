# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | ✅ |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private vulnerability reporting:

<https://github.com/webhossen/file-organizer/security/advisories/new>

Include:

- the affected version (`file-organizer --version`);
- your operating system and Python version;
- steps to reproduce the issue;
- the impact and any suggested fix.

You can expect an acknowledgement within 7 days. Once a fix is available, a
security advisory and patch release will be published.
